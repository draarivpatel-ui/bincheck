Batch CSV inspection

Up to 500 rows, 256 KB

Columns: label, barcode, material, resin, condition. A header row is optional; without one, columns are read as barcode, material, resin, condition, label. Material uses ids like resin-1-pet or glass-jar-bottle. Lines starting with # are ignored. Rows BinCheck cannot identify are listed as errors and never guessed. The bundled sample is an illustrative synthetic dataset, not real household records. Ctrl+Enter (or Cmd+Enter) inside the box runs the inspection.

Wish-cycling and MRF hazard cascade lab

Feed up to 10 copies of each top contaminant into a load of 20 clean #1 PET bottles. Each deterministic stage engages at a fixed count: the same inputs always produce the same failure path. Sliders drive the physical failure modes documented at real materials recovery facilities.

Signed diversion audit export

HMAC-SHA-256

Exports the current profile pair and basket as a signed audit: deterministic JSON, CSV (formula-injection safe) or Markdown, each carrying an HMAC-SHA-256 integrity tag computed in pure JavaScript. Paste a JSON export back below to replay it: any edited byte fails verification. The tag proves integrity, it is not a third-party certificate.
